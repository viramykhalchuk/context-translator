
# Context Translator

Context Translator is a web application for AI-powered text translation with style adaptation.

## Features

- Translation into 7 languages
- Three translation styles: neutral, formal, and conversational
- Translation using Groq API and an LLM
- Simple Gradio web interface
- Input validation and API error handling
- Copy translated text

## Technologies

- Python
- Gradio
- Groq API
- GPT-OSS 20B

## How to run

1. Install dependencies:
   `pip install -r requirements.txt`
2. Run:
   `python app.py`
3. Open the local URL displayed in the terminal.
4. Enter your Groq API key.
5. Choose a language and style, enter text, and translate.
